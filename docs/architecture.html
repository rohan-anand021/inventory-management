Request / Data Flow

1User changes a filter (Time Period, Warehouse, Category, Order Status) in FilterBar.vue, updating shared state in useFilters.
2The active view calls client/src/api.js, which builds query params and calls axios against http://localhost:8001/api/*.
3FastAPI (main.py) applies apply_filters() / filter_by_month() over in-memory lists loaded from server/data/*.json.
4Results are validated against Pydantic response models and returned as JSON.
5Vue stores the response in a raw ref (e.g. allOrders); computed properties derive KPIs, charts, and tables reactively.
